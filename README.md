## 🚀 Getting Started

Since this is a static HTML/CSS website, no backend server or package installation is required.

### 1. Clone the repository

```bash
git clone https://github.com/arman-munshi/My-Portfolio.git
```

### 2. Navigate to the project

```bash
cd My-Portfolio
```

### 3. Open the website

You can simply open:

```text
index.html
```

in a web browser.

Alternatively, you can use the **Live Server** extension in VS Code.

### Using VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
